  LNP MANUFACTURING PROCESS SIMULATION
  UNIFIED INPUT FILE  (lnp_input.txt)

  This is the ONLY file you need to fill in. Save it, then run:
      python lnp_simulation.py

  HOW TO FILL IN THIS FILE:
    Known value  ->  write the number after =       Example: flow_aqueous_mL_min = 9
    Unknown      ->  leave blank after =             Example: flow_aqueous_mL_min =
    REQUIRED     ->  must always have a value (fixed operating conditions)
    Blank and zero are different. Blank = unknown. Zero = the value is zero.
    Do NOT change parameter names on the left side of =
    Numbers only in the value field. No units, no text.
    Text after | on each line is for your reference only. The code ignores it.

  THE FILE HAS THREE SECTIONS:
    SECTION A  ->  Flow rates (the main simulation). You need at least 2 known flow values.
    SECTION B  ->  Concentrations / mass flows for the FEED streams (aqueous, organic, etc.)
                   Optional. If filled, composition of all streams is calculated.
    SECTION C  ->  Concentrations / mass flows for the FINAL PRODUCT stream.
                   Optional. Fill to back-calculate feed compositions, or to verify
                   that your feed data produces the expected final product.

  SECTION B AND C RULES:
    For each component, provide concentration (mg/mL) OR mass flow (mg/min) OR both.
      conc only   ->  mass flow = concentration x flow rate   (calculated)
      mass only   ->  concentration = mass flow / flow rate   (calculated)
      both given  ->  code checks: mass should equal conc x flow rate.
                      If they disagree, a WARNING is shown. The flow rate model
                      (Section A) is the authority and will NOT be changed.
    Key format for Sections B and C:   stream.component.field = value
    Field is either  conc_mg_mL  (concentration)  or  mass_mg_min  (mass flow rate)

  WHAT GETS CALCULATED AUTOMATICALLY IN SECTION B AND C:
    If Section B only  ->  FORWARD: all derived streams calculated from feed data
    If Section C only  ->  BACKWARD: feed concentrations back-calculated from final product
    If both B and C    ->  BOTH: forward from feed, then checks if result matches Section C


  SECTION A  —  FLOW RATES
  The flow solver calculates all unknowns using 7 material balance equations.
  You need at least 2 known flow values (the 4 REQUIRED parameters do not count).
  DOF = 0 is the target (exactly determined system, unique solution).

  Microfluidic Mixing  (M-101 T-Mixer)
  Aqueous phase: mRNA dissolved in citrate buffer, pumped by P-101
  Organic phase: lipids dissolved in ethanol, pumped by P-102
  FRR = Aqueous Flow / Organic Flow  (controls particle size and encapsulation efficiency)

flow_aqueous_mL_min =        | Unit: mL/min  | Typical: 3-15    | Aqueous phase flow (Pump P-101)
flow_organic_mL_min =        | Unit: mL/min  | Typical: 1-5     | Organic phase flow (Pump P-102)
FRR =                        | Unit: none    | Typical: 1-5     | Flow Rate Ratio = Aqueous / Organic
mixer_flow_mL_min =          | Unit: mL/min  | Typical: 4-20    | Mixer output = Aqueous + Organic

  Buffer Dilution  (T-103 Post-Mix Dilution Vessel)
  Dilution buffer (PBS pH 7.4) is added after the mixer to reduce ethanol
  and quench LNP self-assembly. dilution_ratio = buffer flow / mixer output flow.

dilution_ratio = 3           | Unit: none    | Typical: 1-5     | REQUIRED. Buffer added per unit mixer output
dilution_flow_mL_min =       | Unit: mL/min  | Typical: 4-75    | Dilution buffer flow rate
tff_feed_mL_min =            | Unit: mL/min  | Typical: 8-100   | Total flow into TFF = mixer + dilution

  Tangential Flow Filtration  (UF-101, 100 kDa MWCO)
  LNPs are concentrated. Ethanol and buffer salts are removed through the membrane.
  VRR = TFF feed flow / retentate flow. Higher VRR = more concentrated product.

tff_vrr = 6                  | Unit: none    | Typical: 4-10    | REQUIRED. TFF Volume Reduction Ratio
retentate_mL_min =           | Unit: mL/min  | Typical: 1-15    | Purified LNP stream (retained by membrane)
permeate_mL_min =            | Unit: mL/min  | Typical: 5-90    | Waste stream (ethanol + buffer salts removed)

  Cryoprotectant Addition  (T-100 Stabilizer Vessel)
  Trehalose or sucrose solution is added after TFF to protect LNPs during freezing.

cryo_flow_mL_min = 0.5       | Unit: mL/min  | Typical: 0.1-2   | REQUIRED. Cryoprotectant addition flow
after_cryo_flow_mL_min =     | Unit: mL/min  | Typical: 1-17    | Flow after cryo addition = retentate + cryo

  Sterile Filtration  (F-101, 0.22 um Filter)
  Final product is filtered through a 0.22 um membrane before filling.
  A small volume is held up inside the filter housing and is not recovered.

sterile_filter_dead_vol_mL_min = 0.5  | Unit: mL/min  | Typical: 0.1-1  | REQUIRED. Filter hold-up volume
final_product_mL_min =       | Unit: mL/min  | Typical: 1-16    | Final product collected in ST-101


  SECTION B  —  FEED STREAM COMPOSITION  (optional)
  Fill in concentrations or mass flows for the four input streams.
  Derived streams (mixer output, TFF retentate, TFF permeate, final product)
  are calculated automatically by mass conservation and TFF efficiency factors.

  TFF separation efficiencies used in the model:
    mRNA                95% retained (5% lost to permeate)
    Lipids (IL/DSPC/Chol/PEG)   98% retained (2% to permeate)
    Ethanol              5% retained (95% removed by TFF)
    Buffer salts         2% retained (98% removed by TFF)
    Water               10% retained (90% removed by TFF)
  These can be adjusted in the TFF_RETENTION_FRACTION table in lnp_composition.py.
