# Lipid-Nanoparticles
Hi Everyone!!!
This project focuses on developing a low-cost, lab-scale LNP manufacturing system using open-source hardware, 3D-printed components, and controlled multi-stream mixing.
this project is done in two steps:

**Semester Work**
This phase of the project involved developing the foundational process understanding through simulation and flow diagram development, along with research into Process Analytical Technology (PAT). It also included the creation of the P&ID and completion of a preliminary HAZOP analysis, followed by the initial design of the mixing system and overall process layout.
In this phase i also included the python library for composition and simulation for LNPs that includes different variation. There are also user manual for simulation.

**Summer Work**
In this section i introduced the theoretical part to applied lab where I proceed with Fabrication and assembly of four syringe pumps based on the Poseidon open-source design, integrated with an Arduino, CNC Shield V3, and A4988 stepper motor drivers using the AccelStepper library for precise control. The work also included experimental calibration of syringe pump flow rates, where different settings were tested and tuned to achieve consistent output, along with the design and 3D printing of a Multi-Inlet Vortex Mixer (MIVM) to improve mixing efficiency. The system was further refined through iterative testing, troubleshooting, and optimization of both pumping and mixing performance, with each iteration helping to improve accuracy, stability, and overall system reliability.

This repository contains the CAD files, Arduino code, experimental data, process documentation, and project resources developed throughout the project. It serves as a project record, technical handover, and portfolio of the work.
